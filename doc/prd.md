# 背景

开发情感对话机器人agent：
1. 支持chatbox对话；（本次chatbox即可MVP版本、后支持虚拟形象、剧情等）
2. 长期记忆用户交流内容；
3. 恋人角度来进行交流（情感、记忆、人设（温柔、可爱、调皮）、性感（萝莉、御姐））；

# 技术栈
1. TS全栈；
2. 文件存储会话、历史、记忆等；

# 关键设计
1. 记忆模块；（短期记忆、长期记忆）；
2. 工具：（支持联网搜索，优先用已有工具）
3. 情感（喜怒哀乐、情感状态机）
4. 模型支持（千问、deepseek、kimi等接入）

# 约束
1. 模块清晰，一个模块一个目录；
2. 各个模块之间约定协议进行通信；
3. 代码长度不要过于长，良好编程风格，包含注释；
